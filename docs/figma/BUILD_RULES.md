Goal: each screen must match the Figma file **DocOClock** (fileKey `zJRyAML8hv0uEBOXtu5Hpn`, page *Web Version V1*) exactly — layout, components, hover/prototype motion — while **every existing behaviour keeps working** (auth, data, routing, queue logic, booking, prescriptions).

## Rules
1. **Ownership.** Edit only the files listed as OWNED for your unit plus NEW files in the listed locations. Everything else is read-only — especially `index.css`, `tailwind.config.js`, `index.html`, `utils/colorScale.ts`, `contexts/ThemeContext.tsx`, `components/Layout.tsx`, `components/dashboard/**` (shared; if you need a change there, use a local workaround and report it in `sharedGaps`), `storage.ts`, `AuthContext.tsx`, `App.tsx`, `types.ts`, `hooks/**`, `supabase.ts`, SQL, `server/**`, `pdf/**`, `dev-mocks/**`. Use Tailwind arbitrary values (with a short comment) or a co-located `.css` file you create when a token is missing.
2. **No behaviour changes.** Keep every prop, state, effect, handler, route, query, condition and data flow. Restyle / restructure JSX and classes only. Do not rename or change signatures of exports/props. Do not touch data fetching. A Figma control with no existing feature: render it only if purely presentational, otherwise list it under `notImplemented`.
3. **Shared components.** Before changing an existing variant/default of a shared component, grep its usages; if any usage is out of scope (admin, hospital admin, branch manager, assistant, marketing) add a new variant/prop (default = old look) instead.
4. **Theme.** Colours via tokens (`primary`, `secondary`, `medical`, `ink`, `content`, `surface`, `page`…) — no new literal hex/rgba/inline colour except fixed semantic colours tokens.md allows (status colours) and shadows; decorative gradients derive from theme CSS variables. Never hand-write/inline SVG: use exported assets under `/assets/figma/**` (export missing ones from Figma into `public/assets/figma/<unit>/`, checking sha256 against existing files) or a lucide icon only when the glyph clearly matches the Figma icon. Chart series colours come from `useTheme()`.
5. **Motion.** Prototype interactions = CSS transitions with the exact values from Figma: hover/press/change-to = `0.3s cubic-bezier(0,0,.58,1)` (Figma EASE_OUT), screen change = DISSOLVE 0.3s, profile-area changes 0.5s; read each reaction's own transition (`use_figma` read-only snippet below) instead of assuming. Hover-only reveals must also work on `:focus-visible`/`:focus-within`, must not break touch devices, and must respect `prefers-reduced-motion` (`motion-reduce:` variants).
6. **Fonts.** Restyled screens use Instrument Sans (`font-display`) as the root family; Inter (`font-inter`) only where the specs say Figma uses Inter (navbar links, wordmark, dashboard button labels, pagination, table heads, chart axes). Do not flip the global body font.
7. **Git.** Never run a git command that changes state (no commit/checkout/stash/reset/clean/restore/rebase). Read-only git is fine. Other agents edit other files in the same working tree at the same time.
8. **Figma is READ-ONLY.** `use_figma` scripts must only read. Figma MCP tools are deferred: load with ToolSearch `select:mcp__266b791f-9c17-43fc-bfad-9beea37f1098__get_metadata,mcp__266b791f-9c17-43fc-bfad-9beea37f1098__get_design_context,mcp__266b791f-9c17-43fc-bfad-9beea37f1098__get_screenshot,mcp__266b791f-9c17-43fc-bfad-9beea37f1098__get_motion_context,mcp__266b791f-9c17-43fc-bfad-9beea37f1098__use_figma,mcp__266b791f-9c17-43fc-bfad-9beea37f1098__download_assets`; invoke Skill `figma:figma-design-to-code` before `get_design_context`, `figma:figma-use` before `use_figma`, `figma:figma-implement-motion` before `get_motion_context`; pass `skillNames`. `use_figma` output truncates at ~20KB (return compact rows). Page context resets every call: start scripts with `await figma.setCurrentPageAsync(figma.root.children.find(p => p.name === "Web Version V1"))`. On rate-limit errors do local work, back off, retry later.

## Verification (mandatory)
- **Types:** `npx tsc --noEmit -p tsconfig.json 2>&1 | grep -v "^supabase/functions"` must show nothing for your files (18 unrelated Deno errors live in `supabase/functions/*`).
- **Visual:** start the harness (`npx vite --config vite.mock.config.ts --port <YOUR PORT> --strictPort`, Bash run_in_background), screenshot at 1440×900 and 390×844 and compare against `docs/figma/reference/**` PNGs (open both with Read). - **Interactions (hover / press / click / keyboard / reduced motion):** use the headless-Chrome DevTools driver `dev-mocks/tools/cdp.mjs` (`import { launch } from '/abs/path/dev-mocks/tools/cdp.mjs'`; `const c = await launch(<your unique CDP port>)`; `c.viewport(w,h,dpr)`, `c.goto(url)`, `c.eval(js)`, `c.move(x,y)`, `c.click(x,y)`, `c.key(key,code,vk)`, `c.shot(path,{clip,full})`, `c.media([{name:'prefers-reduced-motion',value:'reduce'}])`, `c.close()` in `finally`). Example: `dev-mocks/tools/hover-example.mjs`. Sample `getComputedStyle` at t≈0/90/210/350ms after `c.move()` and compare with the Figma numbers (durations, easing, property deltas).
- **Console:** no errors. **Build:** `npm run build` once at the very end (if it fails in files you do not own, wait and retry; do not touch them).
- Stop your dev server and close your tab / Chrome when done.

## Reusable read-only `use_figma` snippets
- **Reactions of a subtree** (prototype interactions): `const root = await figma.getNodeByIdAsync("ID"); const nodes=[root].concat(root.findAll(n=>"reactions" in n && n.reactions && n.reactions.length>0)).filter(n=>"reactions" in n && n.reactions && n.reactions.length>0); rows = for each reaction/action: [n.id, n.name, n.type, trigger.type, trigger.delay||timeout, action.type, action.navigation, action.destinationId, transition.type, transition.easing.type, transition.duration, transition.direction, overlayRelativePosition]`.
- **Hover / variant deltas:** snapshot both variants (name/type/visible/opacity/x/y/w/h/layoutMode/padding/gap/alignments/fills/strokes/cornerRadius/effects/text/fontSize/weight per node, recursively) and print only the differing keys per path (see `docs/figma/specs/landing-components.md` §5 for outputs produced this way).
- **Component sets used in a subtree:** `root.findAllWithCriteria({types:["INSTANCE"]})` → `await i.getMainComponentAsync()` → parent COMPONENT_SET name / variant name.
- Figma easings: EASE_IN `cubic-bezier(.42,0,1,1)`, EASE_OUT `cubic-bezier(0,0,.58,1)`, EASE_IN_OUT `cubic-bezier(.42,0,.58,1)`, LINEAR; GENTLE/QUICK/BOUNCY/SLOW are springs (report names verbatim; `tokens.md` §7 has the file-wide motion facts).
